ยืนยันตัวตน 2 ขั้นตอน / 2-step sign-in

นอกจากรหัสผ่านแล้ว ต้องกรอกรหัส 6 หลักจากแอปยืนยันตัวตนในโทรศัพท์ทุกครั้งที่เข้าสู่ระบบ ผู้ดูแลระบบต้องเปิดใช้ก่อนจึงจะเปลี่ยนสิทธิ์การเข้าถึงได้ / Besides your password, you enter a 6-digit code from an authenticator app on your phone each time you sign in. Admins need it to change access.

  1. ติดตั้งแอปยืนยันตัวตนในโทรศัพท์ เช่น Google Authenticator หรือ Microsoft Authenticator / Install an authenticator app on your phone, such as Google Authenticator or Microsoft Authenticator.
  2. ในแอป กดเพิ่มบัญชีแล้วสแกนคิวอาร์โค้ดนี้ / In the app, add an account and scan this QR code.
  3. กรอกรหัส 6 หลักที่แอปแสดง / Enter the 6-digit code the app shows.

รหัสกู้คืน: บันทึกไว้ในที่ปลอดภัยตอนนี้ (จะไม่แสดงอีก) ใช้แทนรหัส 6 หลักได้ครั้งละหนึ่งรหัส หากโทรศัพท์หาย / Recovery codes: save them somewhere safe now (they are not shown again). If you lose your phone, each one works once instead of the 6-digit code.



ปิดการยืนยัน 2 ขั้นตอน / Turn off 2-step sign-in
เจ้าของโครงการ / Owner controls
สร้างรหัสตั้งค่าหรือตั้งใหม่รหัสผ่านสำหรับผู้ใช้ที่ตรวจสอบแล้ว การสร้างรหัสจะระงับรหัสผ่านเดิมและออกจากระบบทุกอุปกรณ์ทันที
Issue a setup/reset code only for a verified person. Issuing a code immediately invalidates their old password and sessions.
ส่งรหัสเป็นการส่วนตัว รหัสใช้ได้ครั้งเดียวภายใน 15 นาที อย่าใส่ในลิงก์ / Deliver privately. Valid once for 15 minutes. Never put it in a URL.
